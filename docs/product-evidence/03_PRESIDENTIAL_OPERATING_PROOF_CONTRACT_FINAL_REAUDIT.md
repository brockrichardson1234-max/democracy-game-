# 1. Whole-session sidecar exploit is closed

The repaired contract explicitly prohibits using any of the following as the new proof’s canonical child engine or domain API:

- `IntegratedPartialRuntimeSession`;
- current `ProductionGameSession` alias;
- `ProductionGameView`;
- `availablePlayerActions`;
- `dispatchPlayerCommand`;
- Stage 1 attention helpers;
- an opaque format-11 I10 save.

Therefore this shape no longer satisfies POP0-I1:

```text
new presidential session
→ contains old I10 session
→ reads old ProductionGameView
→ dispatches old action IDs
→ layers administration/UI beside it
```

Reuse is now restricted to lower-level owner state/transitions or non-owning typed adapters.

The proof save must contain direct proof/owner state rather than an opaque synchronized I10 world.

I10 remains a separately instantiated regression fixture and is not advanced in lockstep with POP-0.

The new import checks make this boundary machine-verifiable at I1.

This is sufficient to preserve the graduation rule: if POP-0 passes, its operating composition can become the production candidate without first removing a hidden legacy-session core.

# 2. No-screenplay autonomy exploit is closed

The repair now distinguishes valid configured causes from actor-owned decisions.

## Configurable inputs include

- opening state and relationships;
- the firm’s already-made plant closure and separation schedule;
- scheduled measurement/release dates;
- procedural windows and deadlines;
- inherited Housing records;
- actor objectives, resources, access, and opportunities.

## Owner-derived outputs include

- congressional adoption, sponsorship, introduction, delay, amendment, or abandonment;
- committee/leadership use of procedural opportunities;
- governor and organization response;
- media investigation/publication;
- White House retrieval, analysis, disagreement, synthesis, and escalation;
- recipient response to presidential acts.

A scheduled opportunity is not a scheduled choice.

The contract also requires counterfactual evidence for congressional initiative, media behavior, and White House escalation. Changing a load-bearing input must be capable of changing, delaying, narrowing, or preventing the corresponding initiative without inserting a substitute event to preserve drama.

That is enough to distinguish a deterministic autonomous model from a fixed screenplay.

Modeled downstream estimates must be real evidence or assessment artifacts with:

- analytical owner;
- sources and dependency lineage;
- time and scope;
- support and uncertainty;

They cannot directly write:

- actor/public belief;
- political pressure;
- issue salience;

This preserves the ability to test bounded staff reasoning before Income and Healthcare are implemented without creating fake downstream simulation.
