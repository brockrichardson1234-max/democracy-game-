# 2. R15-01 is closed

## 2.1 Executive branch is not one epistemic actor

The repaired composite now explicitly distinguishes:

```text
source/institution possession
≠ White House index/notice
≠ retrievable-on-request
≠ administration office receipt
≠ presidential receipt
≠ restricted/inaccessible/unknown
```

An agency owning an exact operational record does not cause the White House to know it.

This preserves the accepted Step-5 causal bridge.

## 2.2 Country Watch cannot query hidden federal truth

Country Watch substantive content requires:

- actual receipt by a designated administration monitoring/retrieval process; or
- a direct legitimate retrieval whose execution itself creates a receipt.

Metadata may be shown when an authorized index tells the administration that a report/product exists.

The content cannot be shown until retrieved/received.

This rejects:

```text
HUD knows X
→ President knows X
```

and:

```text
player searches database
→ hidden canonical operational truth appears
```

## 2.3 Public availability is not historical knowledge

A public report may exist without the administration having noticed it.

If the player now retrieves it through a supported public-information action, the receipt occurs now.

The Historical Record cannot backdate that knowledge.

## 2.4 Presidential summary does not imply possession of every source detail

A presidential briefing may convey:

> HUD assesses eight awards as high risk.

without conveying every underlying award record.

The deeper source content requires attachment/receipt or a separate retrieval.

This prevents drill-down from silently widening presidential knowledge.

# 3. Monitoring coverage is honest

The repaired composite distinguishes:

- current monitoring;
- stale monitoring;
- delayed product;
- partial coverage;
- failed feed;
- not monitored;
- source not producing data;
- known-but-unretrieved product;
- access restriction;
- unknown.

Therefore these states cannot collapse:

```text
no adverse condition found
```

```text
no recent evidence
```

```text
nobody is currently monitoring this
```

The contract does not require the White House to monitor every mechanism.

That is important: bounded knowledge can include institutional blind spots.
